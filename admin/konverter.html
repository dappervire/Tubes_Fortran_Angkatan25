Konverter CSV → data kelompok

Ubah hasil Google Form / Google Sheet menjadi file data/kelompok.js. Semua proses berjalan di browser ini; tidak ada data yang dikirim ke mana pun.

1 · Masukkan CSV

  1. Di Google Sheet hasil form: File → Download → Comma-separated values (.csv).
  2. Pilih file CSV-nya di bawah, atau tempel isinya ke kotak teks.
  3. Nama kolom dikenali otomatis selama mengandung kata: kelompok, bidang/topik, judul, abstrak, kunci, anggota, paper/pdf, luaran/tautan, dokumentasi/foto.

2 · Periksa hasil

3 · Simpan sebagai data/kelompok.js

Unduh file ini, lalu timpa data/kelompok.js di folder website. Kalau tombol unduh tidak bekerja, salin teksnya dan tempel ke file tersebut.
